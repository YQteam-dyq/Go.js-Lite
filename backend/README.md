# 网站日志与分析系统 (并行组 B)

## 概述
这是一个完整的网站日志分析系统，提供Access Log查看、访问统计、404错误分析和爬虫识别功能。

## 功能模块

### B1. Access Log 查看器 (`access_log.php`)
- **功能**: 读取 Apache/Nginx access log，分页展示
- **特性**: 
  - 支持按 IP/路径/状态码过滤
  - 分页浏览日志条目
  - 实时过滤和搜索
  - 日志解析和格式化显示

### B2. 访问统计图表 (`access_stats.php`)
- **功能**: 生成访问统计图表
- **特性**:
  - 按小时/天的 PV/UV 趋势图
  - Top 页面访问统计
  - Top 来源 IP 统计
  - 状态码分布图
  - 使用 Chart.js 实现可视化

### B3. 404错误分析 (`error_404.php`)
- **功能**: 单独统计404页面，辅助发现死链
- **特性**:
  - 404错误统计和趋势分析
  - 死链检测和识别
  - 错误时间线分析
  - IP行为分析
  - 修复建议和操作

### B4. 爬虫识别与统计 (`bot_analyzer.php`)
- **功能**: 识别搜索引擎爬虫，单独统计爬虫流量
- **特性**:
  - 多种爬虫识别（Google、Bing、百度等）
  - 爬虫流量统计
  - 爬虫行为模式分析
  - 人机流量对比
  - 爬虫活动时间线

### 主入口 (`log_analysis.php`)
- **功能**: 统一的仪表板界面
- **特性**:
  - 集成所有分析功能
  - 响应式设计
  - 数据导出功能
  - 标签页导航

## 使用方法

### 1. 配置日志路径
修改各个文件中的 `$logPath` 参数，指向您的实际日志文件路径：
```php
// 默认路径
$logPath = '/var/log/nginx/access.log';
// 或 Apache 路径
$logPath = '/var/log/apache2/access.log';
```

### 2. 访问各个功能模块

#### Access Log 查看器
```
http://your-domain.com/backend/access_log.php
```

#### 访问统计图表
```
http://your-domain.com/backend/access_stats.php
```

#### 404错误分析
```
http://your-domain.com/backend/error_404.php
```

#### 爬虫识别与统计
```
http://your-domain.com/backend/bot_analyzer.php
```

#### 统一仪表板
```
http://your-domain.com/backend/log_analysis.php
```

### 3. 过滤和搜索
- 在Access Log查看器中使用URL参数进行过滤：
  - `?ip=192.168.1.1` - 按IP过滤
  - `?path=/api/` - 按路径过滤
  - `?status=404` - 按状态码过滤
  - `?page=2` - 指定页码

### 4. 数据导出
- 使用导出按钮将数据导出为CSV或JSON格式
- 支持所有分析模块的数据导出

## 系统要求

- PHP 7.0+
- Web服务器 (Apache/Nginx)
- 可读的日志文件权限
- Chart.js 库（用于图表显示）

## 日志格式支持

系统支持标准的Apache/Nginx Combined日志格式：
```
192.168.1.1 - - [12/Sep/2026:19:01:16 +0800] "GET /index.php HTTP/1.1" 200 1024 "http://example.com/" "Mozilla/5.0..."
```

## 自定义配置

### 添加新的爬虫识别规则
在 `bot_analyzer.php` 中的 `$botSignatures` 数组添加新的爬虫特征：
```php
'NewBot' => ['newbot', 'custombot']
```

### 自定义图表样式
修改各个文件中的CSS样式来自定义界面外观。

## 安全注意事项

1. 确保日志文件路径安全，不要暴露敏感信息
2. 限制对分析界面的访问权限
3. 定期清理日志数据，避免存储过多敏感信息
4. 在生产环境中使用HTTPS

- 实现数据缓存机制

- 定期归档历史日志数据

## 故障排除

### 常见问题

1. **日志文件无法读取**
   - 检查文件权限
   - 确认文件路径正确
   - 检查文件是否存在

2. **图表不显示**
   - 确认网络连接正常
   - 检查Chart.js库是否正确加载
   - 查看浏览器控制台错误信息

3. **过滤功能不工作**
   - 检查日志格式是否正确
   - 确认过滤参数格式正确
   - 查看服务器错误日志
